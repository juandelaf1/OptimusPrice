## What is VIF?

Variance Inflation Factor measures how much the variance of a regression coefficient is inflated due to multicollinearity.

| VIF Range | Interpretation |
|-----------|----------------|
| 1.0 | No correlation |
| 1-5 | Moderate correlation |
| 5-10 | High correlation |
| >10 | Severe multicollinearity |

## Critical Findings

### 1. Guest Features (total_guests, adults, children, babies)

**VIF > 10^13** — Extreme multicollinearity.

These features are linearly dependent:
- `total_guests = adults + children + babies`

**Action**: Keep `total_guests`, remove `adults`, `children`, `babies` (or use only `total_guests`).

### 2. Temporal Features (arrival_week_number, arrival_month)

**VIF > 1,000** — Severe multicollinearity.

- `arrival_week_number` is 99.5% correlated with `arrival_month`

**Action**: Keep `arrival_month`, remove `arrival_week_number`.

### 3. Night Features (stays_in_weekend_nights, stays_in_week_nights, total_nights)

**Negative VIF** — Perfect multicollinearity.

- `total_nights = stays_in_weekend_nights + stays_in_week_nights`

**Action**: Keep `total_nights`, remove the other two.

### 4. arrival_date

**VIF = 11.12** — High correlation with arrival_month and arrival_week_number.

**Action**: Consider removing if temporal features are simplified.

## Why ElasticNet Handles This

- **L1 penalty** (Lasso): Sets coefficients of redundant features to zero
- **L2 penalty** (Ridge): Shrinks correlated coefficients together
- **ElasticNet**: Combines both, handling groups of correlated features

Tree models (GB, RF) cannot handle this as effectively — they split on correlated features independently, creating redundant paths.
