# Optimus Price

AI-powered pricing for any accommodation.

## Features

- Real-time competitor prices from Booking, Expedia, Hotels.com
- ML predictions optimized for your property
- See potential OTA savings before paying commissions
- Zero setup required

## Tech Stack

Next.js 14 + TypeScript + Tailwind CSS + shadcn/ui
FastAPI + PostgreSQL (Supabase)
Deployed on Vercel + Railway
